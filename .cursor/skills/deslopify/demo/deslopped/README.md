# GenericaAI — Deslopped (React demo)

React + Vite version of the **after** state in the Deslopify demo.

Compare with [`../ai-slop/`](../ai-slop/) (before) and [`../deslopped-static/`](../deslopped-static/) (static after).

## Run locally

```bash
npm install
npm run dev
```

Open the URL shown in the terminal (usually `http://localhost:5173`).

## Stack

- React 19 + TypeScript + Vite
- Tailwind CSS + shadcn/ui-style components
- Components from [21st.dev](https://21st.dev) patterns (bento grid, etc.)

This project exists to demonstrate what Deslopify aims for — not as a starter template for new products.
